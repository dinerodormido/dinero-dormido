# Dinero Dormido

Landing page para captar leads de auditorias iniciales de Dinero Dormido.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Despliegue en Vercel

Importa este repositorio en Vercel. Vercel detecta Next.js automaticamente.

El formulario funciona visualmente y muestra un mensaje de confirmacion local. Mas adelante se puede conectar a Tally, Formspree, Supabase o una API propia.
